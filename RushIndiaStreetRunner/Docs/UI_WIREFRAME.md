## Design Tokens

| Token | Value | Usage |
|-------|-------|-------|
| Primary | #FF6F00 (Orange) | Buttons, headers |
| Secondary | #FFC107 (Yellow) | Highlights, coins |
| Accent | #E91E63 (Pink) | Gems, premium |
| Background | #1A1A2E (Dark Blue) | Dark backgrounds |
| Card BG | #FFFFFF (White) | Card surfaces |
| Text Primary | #FFFFFF | On dark backgrounds |
| Text Secondary | #212121 | On light surfaces |
| Success | #4CAF50 | Unlocked, equipped |
| Danger | #F44336 | Reset, unavailable |

### Font Sizes (TextMeshPro)
- Title: 48pt Bold
- Header: 36pt Bold
- Button: 28pt Bold
- Body: 22pt Regular
- Caption: 18pt Regular

### Button Sizing
- Primary (Play): 300×80px minimum touch target
- Secondary (Nav): 120×120px minimum
- All buttons: 48dp minimum touch area
