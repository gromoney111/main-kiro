## The 5 Most Important Steps

### 1. Use the Endless Runner Template
Don't build from scratch! Buildbox's "Martian Marathon" template gives you:
- Running character
- Lane switching
- Jumping & sliding
- Coins & obstacles
- Score & game over

You're already 60% done!

### 2. Just Swap the Art
Buildbox's strength is swapping assets, not coding:
- Astronaut to Indian Chaiwala (Mixamo)
- Mars rocks to Auto-rickshaws (Sketchfab)
- Mars terrain to Indian streets (texture sites)
- Sci-fi music to Bollywood beats (Pixabay)

### 3. Start with 3 Cities, Not 15
Launch faster:
- v1.0: Jaipur + Mumbai + Delhi
- v1.1: Add Bangalore + Goa (1 month later)
- v1.2: Add 3 more cities (every month)

This keeps players excited about updates!

### 4. AdMob = Your Money Machine
Setup is just:
1. Create AdMob account (free)
2. Get 3 ad unit IDs (banner, interstitial, rewarded)
3. Paste IDs in Buildbox Settings -> Done!

Place ads:
- Banner: Always on menus
- Interstitial: After every 3rd game over
- Rewarded: "Watch Ad +50 coins" button (most profitable!)

### 5. Test on REAL Phone Before Publishing
Use Buildbox Preview app (free on Play Store):
1. Install Buildbox Preview on Android phone
2. In Buildbox PC: File -> Preview on Device
3. Scan QR code from phone
4. Game streams instantly!

NEVER publish without testing on real device.

## GO/NO-GO Decision Helper

### Choose Buildbox 3 IF:
- You have 0 coding experience
- You want to launch in 2-4 weeks
- You're OK with drag-and-drop interface
- You want mobile-first game
- Budget is under $300

### Don't Choose Buildbox 3 IF:
- You want advanced 3D graphics (use Unity)
- You want complex multiplayer (use Unreal)
- You want PC/console version (Buildbox is mobile-focused)
- You want completely free solution (use GDevelop instead)
