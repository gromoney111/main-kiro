## Phone Testing Checklist

Before publishing, test these on a REAL Android phone:

- [ ] Game opens without crashing
- [ ] Splash screen shows for 2-3 seconds
- [ ] Main menu has all buttons
- [ ] Play button -> City Selection
- [ ] Each city loads correctly
- [ ] Player runs forward automatically
- [ ] Swipe LEFT changes lane
- [ ] Swipe RIGHT changes lane
- [ ] Swipe UP makes player jump
- [ ] Swipe DOWN makes player slide
- [ ] Coins can be collected
- [ ] Score increases over time
- [ ] Hitting obstacle = game over
- [ ] Game Over shows score and high score
- [ ] "Watch Ad" button works (will show test ad)
- [ ] "Try Again" restarts the run
- [ ] Pause button works during gameplay
- [ ] Sound effects play
- [ ] Background music plays
- [ ] Sound toggle works in Settings
- [ ] Music toggle works in Settings
- [ ] Coins persist after closing app
- [ ] High score persists after closing app

If ALL boxes checked = ready to publish!

## Common Mistakes to AVOID

1. DON'T publish without testing on real phone
2. DON'T forget to backup your keystore file
3. DON'T use copyrighted music (search "royalty free")
4. DON'T use copyrighted brand names (no "Subway Surfers India")
5. DON'T promise features in description that don't exist
6. DON'T use real photos of celebrities or trademarks
7. DON'T set unrealistic IAP prices (Indian users prefer Rs.49-499 range)
8. DON'T show ads more than once per minute
9. DON'T request unnecessary phone permissions
10. DON'T skip the privacy policy step
